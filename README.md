# 🐾 WarmPaws – Pet Care in Winter

A cozy winter companion platform designed for pet owners to ensure their furry friends stay warm, safe, and healthy during the cold season. Users can explore local pet care services, winter pet clothing, grooming options, and expert tips — all in one friendly interface.

## 🌐 Live URL

🔗 [Visit WarmPaws Live](https://a09-pet-paw.web.app)

## 🎯 Purpose

WarmPaws helps pet owners find and book essential winter care services for their beloved pets. From thermal coat fittings to paw healing therapy, our platform connects you with trusted providers who specialize in keeping pets comfortable during the cold months.

## ✨ Key Features

- **🔐 User Authentication** - Secure login/register with email/password and Google Sign-in
- **🛡️ Protected Routes** - Service details accessible only to logged-in users
- **📱 Fully Responsive** - Optimized for mobile, tablet, and desktop devices
- **🎠 Interactive Slider** - Winter-themed hero carousel showcasing cozy pet outfits
- **🐕 Winter Care Services** - Browse 9+ specialized pet care services with ratings and pricing
- **📅 Service Booking** - Easy booking form with success notifications
- **👤 User Profile** - View and update profile information (name, photo)
- **🔑 Password Recovery** - Forgot password functionality with email reset
- **❄️ Winter Care Tips** - Expert advice for keeping pets safe in cold weather
- **👨‍⚕️ Meet Our Vets** - Professional veterinary team profiles

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Ashraf1551/a09-pet-paw.git
```

2. Install dependencies

```bash
npm install
```

3. Create `.env.local` file with your Firebase config

```env
VITE_APIKEY=your_api_key
VITE_AUTHDOMAIN=your_auth_domain
VITE_PROJECTEDID=your_project_id
VITE_STORAGEBUCKET=your_storage_bucket
VITE_MESSAGINGSENDERID=your_messaging_sender_id
VITE_APPID=your_app_id
```

4. Run the development server

```bash
npm run dev
```
